# alu-shell

Shell scripting projects completed as part of the **Introduction to Linux and IT Tools** course at **African Leadership University (ALU)**.

The projects cover essential Linux and Bash concepts, including commands, variables, I/O redirection, loops, permissions, processes, and signals.

**Language:** Shell / Bash

## Projects

| Project                                 | Description                                                                   |
| --------------------------------------- | ----------------------------------------------------------------------------- |
| **basics**                              | Fundamental Linux commands and Shell scripting.                               |
| **init_files_variables_and_expansions** | Shell initialization files, variables, and expansions.                        |
| **io_redirections_and_filters**         | I/O redirection, pipes, and filtering commands such as `grep`.                |
| **loops_conditions_and_parsing**        | Loops, conditionals, and text parsing, including Apache log analysis.         |
| **permissions**                         | Linux file permissions, ownership, and symbolic links.                        |
| **processes_and_signals**               | Process management and signal handling, including start/stop/restart scripts. |

## Standalone Scripts

| File             | Description                                               |
| ---------------- | --------------------------------------------------------- |
| `4-if_9_say_hi`  | Uses a `while` loop to print `"Hi"` on the 9th iteration. |
| `user-input.sh`  | Prompts the user to enter their username.                 |
| `user-input1.sh` | Simple script for receiving user input.                   |
